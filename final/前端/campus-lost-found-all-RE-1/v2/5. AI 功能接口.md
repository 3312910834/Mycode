# 校园失物招领系统前端对接文档（最终版）

## 1. 项目基础信息

- 项目名称：`campus-lost-found`
- 本地基础地址：

​```text
http://localhost:8080/campus-lost-found
```

- 所有接口返回格式：`JSON`
- 编码：`UTF-8`

------

## 2. 当前 AI 功能最终方案

本项目当前保留并联调的 AI 功能如下：

### 功能 1：一键发布（基于 VLM 的图片识别）

用户上传一张拾获物品图片，系统自动识别并生成：

- 标题 `title`
- 分类 `category`
- 描述 `description`

用于：**发布招领页面** 自动填表。

------

### 功能 2：AI 描述找物（文本智能搜索）

用户输入丢失物品的文字描述，系统通过大模型语义理解，在招领信息中搜索可能相关的结果。

用于：**搜索页 / 首页搜索入口**

------

### 功能 3：智能匹配助手（自动推荐）

当用户发布寻物信息后，系统自动根据失物描述，推荐可能匹配的招领信息。

用于：**寻物详情页 / 发布成功页**

------

## 3. 当前前端可直接调用的 AI 接口

------

### 3.1 一键发布（图片自动识别）

#### 接口地址

text



```
POST /foundapi/autoFillByImage
```

#### 完整地址

text



```
http://localhost:8080/campus-lost-found/foundapi/autoFillByImage
```

#### 请求方式

```
POST
```

#### 参数提交方式

text



```
application/x-www-form-urlencoded
```

#### 请求参数

| 参数名   | 类型   | 必填 | 说明     |
| -------- | ------ | ---- | -------- |
| imageUrl | string | 是   | 图片地址 |

#### 请求示例

text



```
imageUrl=https://example.com/item.jpg
```

#### 返回示例

JSON



```
{
  "code": 200,
  "message": "识别成功",
  "data": {
    "title": "黑色皮革男士钱包",
    "category": "卡包/钱包",
    "description": "黑色皮质钱包，边角有轻微磨损，内有校园卡一张"
  }
}
```

#### 异常返回示例

JSON



```
{
  "code": 200,
  "message": "识别成功",
  "data": {
    "title": "拾获物品",
    "category": "其他",
    "description": "AI识别异常",
    "error": "具体错误信息"
  }
}
```

#### 前端页面接入建议

页面位置：**发布招领页**

前端建议新增：

- 图片上传控件
- `AI自动识别` 按钮

交互流程：

1. 用户上传图片
2. 前端拿到图片 URL
3. 调用 `/foundapi/autoFillByImage`
4. 将返回结果自动填充到表单：
   - 标题输入框
   - 分类选择框
   - 描述文本框
5. 用户可以手动修改后再正式提交 `/foundapi/publish`

#### 前端注意事项

- AI 结果只做“辅助填写”

- 用户必须可以手动修改

- 若返回

   

  ```
  data.error
  ```

  ，前端应提示：

  - `AI识别失败，请手动填写`

------

### 3.2 AI 描述找物 / 智能匹配

> 说明：该接口既可用于“用户主动搜索”，也可用于“系统自动推荐”。

#### 接口地址

text



```

#### 完整地址

text



```
http://localhost:8080/campus-lost-found/lostapi/smartMatch

#### 请求方式

```
POST

#### 参数提交方式

text



```

```

#### 请求参数

| 参数名   | 类型   | 必填 | 说明               |
| -------- | ------ | ---- | ------------------ |

#### 请求示例

      },
      {
        "index": 9,

        "reason": "捡到教材，属于书本类物品，与描述中的几本书较为接近"
      }
    ]
  }
}
```

JSON



```
{
  "code": 400,
  "message": "寻物描述不能为空"
}
```

#### 服务异常示例

JSON



```
{
  "code": 500,
  "message": "智能匹配服务异常：xxx"
}

------

### 4.1 场景一：用户主动搜索（AI 描述找物）

#### 使用位置

- 首页搜索区
- 寻物搜索页
- 失物检索页

#### 页面建议

- 一个文本输入框
- 一个按钮：`AI帮我找`

#### 交互流程

1. 用户输入失物描述
2. 点击 `AI帮我找`

- 相似度

JSON



```
{
  "code": 200,
  "message": "识别成功",

    "title": "拾获物品",

  }
}

- 若 `data.error` 存在，则提示用户“AI识别失败，请手动填写”
- 若 `matchCount = 0`，提示“暂无匹配结果”
- 网络异常统一提示“请求失败，请稍后重试”

如果使用 AI 自动生成前端页面，请遵守以下规则：

text



```

```

text



```

```

1. 功能场景是三个：

- 发布招领页：AI 自动识别图片并回填表单
- 搜索页：首页/搜索页的 AI 描述找物
