# 校园失物招领系统前端联调验收清单

## 一、联调目标

当前需要联调的 AI 功能共 2 个接口、3 个页面场景：

### 接口
1. `POST /foundapi/autoFillByImage`
2. `POST /lostapi/smartMatch`

### 页面场景
1. 发布招领页 —— AI 自动识别图片并填表
2. 搜索页 / 首页搜索框 —— AI 描述找物
3. 发布寻物成功页 / 寻物详情页 —— 智能匹配推荐

---

## 二、基础检查

### 1. 基础地址是否正确
前端所有请求应基于：

​```text
http://localhost:8080/campus-lost-found
```

------

### 2. 请求方式是否正确

- `/foundapi/autoFillByImage` 必须使用 `POST`
- `/lostapi/smartMatch` 必须使用 `POST`

------

### 3. POST 参数格式是否正确

后端通过 `req.getParameter(...)` 获取参数，因此前端应使用：

text



```
Content-Type: application/x-www-form-urlencoded
```

------

## 三、接口 1 验收：一键发布（VLM）

### 接口信息

text



```
POST /foundapi/autoFillByImage
```

### 参数

| 参数名   | 是否必填 | 说明     |
| -------- | -------- | -------- |
| imageUrl | 是       | 图片地址 |

------

### 验收项 1：接口是否能成功返回

#### 操作

前端上传图片后，点击“AI自动识别”

#### 预期结果

返回结构应类似：

JSON



```
{
  "code": 200,
  "message": "识别成功",
  "data": {
    "title": "钥匙",
    "category": "个人物品",
    "description": "两把金属钥匙，带有圆形钥匙环..."
  }
}
```

------

### 验收项 2：表单是否自动填充

#### 预期结果

前端应自动将以下字段填入发布招领表单：

- 标题输入框 ← `data.title`
- 分类输入框 / 下拉框 ← `data.category`
- 描述文本框 ← `data.description`

------

### 验收项 3：用户是否可以继续手动修改

#### 预期结果

AI 自动识别后，用户仍然可以：

- 修改标题
- 修改分类
- 修改描述

不能锁死表单。

------

### 验收项 4：异常时是否有提示

#### 常见异常

- 图片地址为空
- AI识别失败
- 网络错误

#### 预期结果

页面应提示：

- `图片不能为空`
- `AI识别失败，请手动填写`
- `请求失败，请稍后重试`

------

## 七、发布流程联调验收

### 场景：发布招领

#### 流程

1. 上传图片
2. 点击 AI 自动识别
3. 自动填充表单
4. 手动确认/修改
5. 点击发布
6. 成功提交 `/foundapi/publish`

#### 验收结果

整个流程顺畅，无阻塞，无明显异常提示。

------

### 场景：发布寻物

#### 流程

1. 填写寻物描述
2. 点击发布
3. 成功后进入成功页或详情页
4. 自动展示智能匹配推荐

#### 验收结果

匹配结果能正常出现，不影响原始发布流程。

------

## 八、接口返回验收标准

### 一键发布接口成功标准

必须满足：

- `code = 200`
- `data.title` 有值
- `data.category` 有值
- `data.description` 有值

------

### 智能匹配接口成功标准

必须满足：

- `code = 200`
- `data.matchCount` 存在
- `data.matches` 为数组

------

## 九、常见问题排查

### 问题 1：后端返回 400

#### 原因

参数没传或参数名错误。

#### 检查

- `/foundapi/autoFillByImage` 是否传了 `imageUrl`
- `/lostapi/smartMatch` 是否传了 `lostText`

------

### 问题 2：前端拿不到参数

#### 原因

POST 请求没用 `application/x-www-form-urlencoded`

#### 检查

请求头是否正确。

------

### 问题 3：接口返回成功但页面没显示

#### 原因

前端字段取值错了。

#### 检查

- 一键发布取的是 `data.title/data.category/data.description`
- 智能匹配取的是 `data.matchCount/data.matches`

------

### 问题 4：页面卡死或白屏

#### 原因

前端没有处理异常分支。

#### 检查

是否兼容：

- `code`
- `message`
- `error`
- 空数组
- 网络异常

------

## 十、联调完成标准

满足以下条件即可视为联调完成：

### 1. 一键发布成功

- 上传图片可自动识别
- 可自动填表
- 用户可修改
- 可继续发布成功

### 2. AI 描述找物成功

- 输入描述后可返回匹配结果
- 页面可展示结果
- 空结果和异常情况有提示

### 3. 智能匹配推荐成功

- 发布寻物后能自动推荐匹配结果
- 页面展示正常
- 不影响原有发布流程

------
